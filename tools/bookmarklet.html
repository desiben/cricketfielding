Get the CricClubs bookmarklet

A bookmark that reads a player's CricClubs profile and copies their record, ready to paste into the fielding board. It reads the page you are already looking at — nothing is sent anywhere, and it works on pages that need you to be logged in.

Grab CricClubs stats

Drag this button onto your bookmarks bar.

If you cannot drag it

  1. Make a new bookmark of any page, then edit it.
  2. Name it Grab CricClubs stats.
  3. Replace its address with the text below.

Using it

  1. Open a player's CricClubs profile.
  2. Click the bookmark. It confirms whose record it took.
  3. In the board, open Player records → Import a player and paste.

One click takes every league on the profile, not just the tab on screen. If the button ever stops working — CricClubs redesigning their pages would do it — copy the profile page itself with ⌘A then ⌘C and paste that into the same box instead. The board reads both.

On a phone

Bookmarklets are awkward on mobile: iOS wants you to save a bookmark and then edit its address, Android wants you to type the bookmark's name into the address bar. Importing records is a once-a-season job, so it is easier on a laptop. The board itself stays made for the boundary rope.
